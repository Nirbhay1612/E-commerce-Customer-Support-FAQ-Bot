## Overview

🛒 E-commerce Customer Support FAQ Bot

📌 Overview

The E-commerce Customer Support FAQ Bot is an AI-powered chatbot designed to automate customer support and provide instant answers to frequently asked questions. It helps customers get quick and accurate information about orders, shipping, returns, refunds, payment methods, and other e-commerce-related queries.

Built using Python, Streamlit, and LLM technology, this project demonstrates the practical application of AI chatbots in customer service and business automation.

🎯 Why I Created This Project

I created this project to solve common challenges faced by e-commerce businesses, such as repetitive customer queries, delayed responses, and manual support workloads.

The goal is to build an intelligent, user-friendly FAQ chatbot that can:

- Automate repetitive customer support questions.
- Provide instant responses to frequently asked queries.
- Improve customer experience and accessibility.
- Reduce the workload of customer support teams.
- Demonstrate practical AI integration and chatbot development skills.

✨ Key Highlights

- 🤖 AI-Powered Conversations: Uses an LLM to generate helpful responses to customer queries.
- 🛍️ E-commerce FAQ Support: Handles common questions about orders, delivery, returns, refunds, and payments.
- ⚡ Instant Responses: Provides quick answers without requiring manual support for every FAQ.
- 💬 Interactive Chat Interface: User-friendly chatbot interface built with Streamlit.
- 🔌 API Integration: Integrates with an LLM API for AI-powered responses.
- 🧩 Modular Architecture: Designed to support future improvements and additional business features.
- 📱 Responsive Experience: Designed for convenient interaction through a web-based interface.

- Suggested quick reply buttons

## How to Run

1. Open the project folder in **VS Code**
2. Open `index.html`
3. Right click → **Open with Live Server**  
   **OR**
4. Simply double-click `index.html` to open in browser
